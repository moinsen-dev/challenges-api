# Code of Conduct

Be decent. Assume the other person is trying to build something good.

Concretely: no harassment, no personal attacks, no demeaning remarks about who
somebody is. Disagree about the work, not about the person. If you are asked to
stop something, stop.

This project builds public leaderboards, and it ships moderation tools for a
reason: a scoreboard with strangers on it needs boundaries. The same applies in
here.

Report anything that needs attention to **business@moinsen.dev**. Reports are
handled by the maintainer, in confidence.
